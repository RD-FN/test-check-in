# เว็บเช็คชื่อ คลาส Claude AI

เวอร์ชันล่าสุดและการเปลี่ยนแปลงแต่ละเวอร์ชัน ดูได้ที่ [CHANGELOG.md](CHANGELOG.md)

เว็บเช็คชื่อผู้เข้าเรียนแบบออนไลน์ ผู้เรียนค้นหาชื่อตัวเอง กดเช็คชื่อ แล้วเซ็นลายเซ็นบนจอ ระบบบันทึกเวลาที่มาและแยกว่าตรงเวลาหรือสาย ข้อมูลและการล็อกอินทั้งหมดอยู่บน [Supabase](https://supabase.com)

ใช้ได้ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์

## ความสามารถ

- รายชื่อผู้เรียนพร้อมช่องค้นหา และตัวกรอง ทั้งหมด / มาแล้ว / ยังไม่มา
- เซ็นชื่อด้วยนิ้ว เมาส์ หรือปากกาสไตลัส ผู้เรียนไม่ต้องเข้าสู่ระบบ
- เวลาเช็คชื่อและสถานะสายคิดที่เซิร์ฟเวอร์ตามเวลาประเทศไทย เช็คชื่อซ้ำในวันเดียวกันไม่ได้
- ทุกเครื่องเห็นการเช็คชื่อทันทีแบบเรียลไทม์
- ผู้สอนเข้าสู่ระบบด้วย Google หรือลิงก์ทางอีเมล แล้วจะได้เครื่องมือผู้สอน: นำเข้ารายชื่อจาก CSV หรือ Excel, เพิ่มชื่อทีละคน, ตั้งชื่อคลาส เวลาเริ่ม และนาทีผ่อนผัน, ดูวันย้อนหลัง, ดูลายเซ็น, ยกเลิกการเช็คชื่อ, ดาวน์โหลด CSV ของวันที่เลือกหรือประวัติทั้งหมด

## ฐานข้อมูล (Supabase)

โปรเจกต์ `claude-ai-checkin` (สิงคโปร์) สร้างและตั้งค่าตารางไว้แล้ว

| ตาราง | เก็บอะไร | ใครเข้าถึงได้ |
|---|---|---|
| `students` | รายชื่อผู้เรียน | ทุกคนอ่านได้ ผู้สอนแก้ไขได้ |
| `checkins` | การเช็คชื่อ: วันที่ เวลา สถานะ สายกี่นาที | ทุกคนอ่านได้ ผู้สอนลบได้ เพิ่มได้ผ่านฟังก์ชัน `check_in` เท่านั้น |
| `checkin_signatures` | ลายเซ็น | ผู้สอนเท่านั้น |
| `settings` | ชื่อคลาส เวลาเริ่ม นาทีผ่อนผัน | ทุกคนอ่านได้ ผู้สอนแก้ไขได้ |
| `admins` | อีเมลผู้สอน | ไม่เปิดให้เข้าถึงผ่านเว็บ |

**เพิ่มผู้สอนคนอื่น** ใน Supabase ไปที่ SQL Editor แล้วรัน

```sql
insert into public.admins (email) values ('อีเมลผู้สอน@example.com');
```

## ตั้งค่าการล็อกอิน (ทำครั้งเดียวใน Supabase Dashboard)

### 1. ตั้ง URL ของเว็บ (จำเป็น ทั้ง Google และลิงก์ทางอีเมล)

**Authentication > URL Configuration**
- Site URL: `https://rd-fn.github.io/test-check-in/`
- Redirect URLs: เพิ่ม `https://rd-fn.github.io/test-check-in/`

### 2. เปิดล็อกอินด้วย Google

1. ใน [Google Cloud Console](https://console.cloud.google.com/apis/credentials) สร้าง **OAuth client ID** ประเภท **Web application**
   - Authorized JavaScript origins: `https://rd-fn.github.io`
   - Authorized redirect URIs: `https://qyiqokpgftazgdxohwxq.supabase.co/auth/v1/callback`
2. คัดลอก Client ID และ Client Secret
3. ใน Supabase ไปที่ **Authentication > Sign In / Providers > Google** เปิดใช้งาน แล้ววาง Client ID และ Client Secret แล้วกด Save

ระหว่างที่ยังไม่ได้ตั้ง Google ใช้ปุ่ม "ส่งลิงก์" ทางอีเมลแทนได้เลย

## ขึ้นเว็บด้วย GitHub Pages

1. ไปที่ **Settings > Pages** ของ repository
2. ที่ Source เลือก **Deploy from a branch** เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด Save
3. รอประมาณ 1 ถึง 2 นาที เว็บจะอยู่ที่ `https://rd-fn.github.io/test-check-in/`

## วิธีใช้

**ผู้สอน**
1. กด **เข้าสู่ระบบผู้สอน** ท้ายหน้า แล้วเลือก Google หรือส่งลิงก์ทางอีเมล
2. ใน **เครื่องมือผู้สอน** ลากไฟล์รายชื่อ (CSV หรือ Excel) มาวาง ไฟล์ควรมีคอลัมน์ `ชื่อ` และถ้ามี `นามสกุล` กับ `รหัส` ด้วยก็ได้ ดูตัวอย่างที่ [`examples/students-template.csv`](examples/students-template.csv)
3. ตั้งชื่อคลาส เวลาเริ่ม และนาทีที่ผ่อนผันก่อนนับว่าสาย

**ผู้เรียน**
1. เปิดลิงก์เว็บ พิมพ์ชื่อตัวเองในช่องค้นหา
2. กด **เช็คชื่อ** เซ็นชื่อ แล้วกด **ยืนยันเข้าเรียน**

## ออกเวอร์ชันใหม่

1. แก้ `version.js`: เปลี่ยน `version` และ `released` แล้วเพิ่มรายการใหม่ไว้บนสุดของ `changes`
2. ใน `index.html` เปลี่ยน `?v=` ท้ายชื่อไฟล์ทุกจุดให้เป็นเลขเวอร์ชันใหม่ เพื่อให้เบราว์เซอร์โหลดไฟล์ใหม่ทันที
3. จดสิ่งที่เปลี่ยนใน `CHANGELOG.md`

หลักการตั้งเลข `X.Y.Z`: X เปลี่ยนใหญ่, Y เพิ่มความสามารถใหม่, Z แก้ปัญหาเล็กน้อย

## ข้อควรรู้เรื่องความปลอดภัย

- คีย์ใน `config.js` เป็นคีย์สาธารณะ (anon) ใส่ในเว็บได้ สิทธิ์ทั้งหมดคุมด้วย Row Level Security ในฐานข้อมูล
- **ห้าม**ใส่ `service_role` key หรือรหัสผ่านฐานข้อมูลลงใน repository
- ใครมีลิงก์เว็บก็กดเช็คชื่อให้คนอื่นได้ เช่นเดียวกับใบเซ็นชื่อกระดาษ ลายเซ็นจึงเป็นหลักฐานยืนยันอีกชั้น

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| กดเข้าสู่ระบบด้วย Google แล้วขึ้น "provider is not enabled" | เปิด Google ใน Supabase ตามหัวข้อ "เปิดล็อกอินด้วย Google" |
| ล็อกอินแล้วเด้งไป `localhost` | ตั้ง Site URL และ Redirect URLs ตามหัวข้อ "ตั้ง URL ของเว็บ" |
| "บัญชีนี้ไม่มีสิทธิ์ผู้สอน" | เพิ่มอีเมลลงตาราง `admins` |
| ท้ายหน้าขึ้น "การอัปเดตอัตโนมัติขัดข้อง" | ข้อมูลยังโหลดได้ปกติ หน้าเว็บจะลองเชื่อมต่อใหม่เอง |
| นำเข้าไฟล์แล้วไม่พบรายชื่อ | ตรวจว่ารายชื่ออยู่ในชีตแรกของไฟล์ และมีคอลัมน์ชื่อ |
