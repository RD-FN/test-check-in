# เว็บเช็คชื่อ คลาส Claude AI

เว็บเช็คชื่อผู้เข้าเรียนแบบออนไลน์ ผู้เรียนค้นหาชื่อตัวเอง กดเช็คชื่อ แล้วเซ็นลายเซ็นบนจอ ระบบบันทึกเวลาที่มาและแยกว่าตรงเวลาหรือสาย ข้อมูลทั้งหมดบันทึกลง Google Sheets ทันที

ใช้ได้ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์

## ความสามารถ

- รายชื่อผู้เรียนพร้อมช่องค้นหา และตัวกรอง ทั้งหมด / มาแล้ว / ยังไม่มา
- เซ็นชื่อด้วยนิ้ว เมาส์ หรือปากกาสไตลัส
- บันทึกเวลาที่มา และบอกว่าสายกี่นาทีตามเวลาเริ่มคลาสที่ตั้งไว้
- ทุกเครื่องที่เปิดหน้าเว็บเห็นการเช็คชื่อตรงกัน (อัปเดตทุก 8 วินาที)
- โหมดผู้สอน (ใส่ PIN): นำเข้ารายชื่อจาก CSV หรือ Excel, เพิ่มชื่อทีละคน, ตั้งเวลาเริ่มคลาส, ดูวันย้อนหลัง, ยกเลิกการเช็คชื่อ, ดาวน์โหลดผลเป็น CSV

## โครงสร้างไฟล์

```
├── index.html                  หน้าเว็บ
├── config.js                   ค่าตั้งค่า (แก้ไฟล์นี้ไฟล์เดียว)
├── assets/
│   ├── style.css               หน้าตาเว็บ
│   └── app.js                  การทำงานของเว็บ
├── apps-script/
│   ├── Code.gs                 ตัวเชื่อม Google Sheets (วางใน Apps Script)
│   └── appsscript.json         ตั้งค่าโปรเจ็กต์ Apps Script
└── examples/
    └── students-template.csv   ตัวอย่างไฟล์รายชื่อ
```

## ติดตั้ง

### 1. เตรียม Google Sheet

1. สร้าง Google Sheet ใหม่ ตั้งชื่ออะไรก็ได้ เช่น "เช็คชื่อ Claude AI"
2. ไปที่เมนู **ส่วนขยาย > Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้ววางโค้ดจาก [`apps-script/Code.gs`](apps-script/Code.gs) แทน แล้วกดบันทึก
4. ตั้ง PIN ผู้สอน: กดไอคอนเฟือง **การตั้งค่าโปรเจ็กต์** เลื่อนลงไปที่ **พร็อพเพอร์ตี้ของสคริปต์** แล้วกด **เพิ่มพร็อพเพอร์ตี้ของสคริปต์**
   - พร็อพเพอร์ตี้: `ADMIN_PIN`
   - ค่า: PIN ที่ต้องการ เช่น `482913`

   PIN เก็บไว้ใน Google เท่านั้น ไม่อยู่ในโค้ด จึงไม่หลุดขึ้น GitHub

### 2. เปิดใช้เป็นเว็บแอป

1. ใน Apps Script กด **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่**
2. กดไอคอนเฟืองข้าง "เลือกประเภท" แล้วเลือก **เว็บแอป**
3. ตั้งค่า
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
4. กด **ทำให้ใช้งานได้** และอนุญาตสิทธิ์เข้าถึง Google Sheets
   (ถ้าเจอหน้าเตือน "Google ไม่ได้ยืนยันแอปนี้" ให้กด ขั้นสูง > ไปที่โปรเจ็กต์ เพราะเป็นสคริปต์ของคุณเอง)
5. คัดลอก **URL ของเว็บแอป** ที่ลงท้ายด้วย `/exec`

ทดสอบได้โดยเปิด URL นั้นในเบราว์เซอร์ ถ้าเห็น `"Attendance API is running"` แสดงว่าพร้อมใช้งาน

### 3. ใส่ URL ในเว็บ

เปิดไฟล์ `config.js` แล้ววาง URL ลงใน `SHEETS_URL`

```js
window.ATTENDANCE_CONFIG = {
  SHEETS_URL: "https://script.google.com/macros/s/xxxxxxxx/exec",
  CLASS_NAME: "Claude AI",
  POLL_SECONDS: 8,
  LOCAL_PIN: "1234"
};
```

### 4. ขึ้นเว็บด้วย GitHub Pages

1. อัปโหลดไฟล์ทั้งหมดขึ้น repository บน GitHub
2. ไปที่ **Settings > Pages**
3. ที่ Source เลือก **Deploy from a branch** เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด Save
4. รอประมาณ 1 ถึง 2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repository>/`

จะเอาไปวางบนเซิร์ฟเวอร์อื่นก็ได้ เพราะเป็นไฟล์ static ทั้งหมด ไม่ต้องติดตั้งอะไรเพิ่ม

## วิธีใช้

**ผู้สอน**
1. เปิดเว็บ กดปุ่ม **โหมดผู้สอน** ท้ายหน้า แล้วใส่ PIN
2. ใน **เครื่องมือผู้สอน** ลากไฟล์รายชื่อ (CSV หรือ Excel) มาวาง
   ไฟล์ควรมีคอลัมน์ `ชื่อ` และถ้ามี `นามสกุล` กับ `รหัส` ด้วยก็ได้ ดูตัวอย่างที่ [`examples/students-template.csv`](examples/students-template.csv)
3. ตั้งเวลาเริ่มคลาส และจำนวนนาทีที่ผ่อนผันก่อนนับว่าสาย

**ผู้เรียน**
1. เปิดลิงก์เว็บ พิมพ์ชื่อตัวเองในช่องค้นหา
2. กด **เช็คชื่อ** เซ็นชื่อ แล้วกด **ยืนยันเข้าเรียน**

## ข้อมูลใน Google Sheets

ระบบสร้างชีตให้อัตโนมัติเมื่อใช้งานครั้งแรก

| ชีต | เก็บอะไร |
|---|---|
| `Students` | รายชื่อผู้เรียน: id, รหัส, ชื่อ, ลำดับ |
| `Checkins` | การเช็คชื่อ: วันที่, รหัส, ชื่อ, เวลา, สถานะ (มาเรียน/สาย), สายกี่นาที, ลายเซ็น |
| `Settings` | เวลาเริ่มคลาส และนาทีที่ผ่อนผัน |

ลายเซ็นเก็บเป็นข้อความรูปภาพ (ขึ้นต้นด้วย `data:image/png;base64,`) ดูเป็นรูปได้จากหน้าเว็บ

## แก้ไขภายหลัง

- **แก้โค้ดใน Apps Script** ต้องกด **ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > แก้ไข (ไอคอนดินสอ) > เวอร์ชัน: เวอร์ชันใหม่** ทุกครั้ง URL จะยังเป็นอันเดิม
- **เปลี่ยน PIN** แก้ค่า `ADMIN_PIN` ในพร็อพเพอร์ตี้ของสคริปต์ มีผลทันทีไม่ต้อง deploy ใหม่
- **เปลี่ยนชื่อคลาส** แก้ `CLASS_NAME` ใน `config.js`

## ข้อควรรู้เรื่องความปลอดภัย

- การนำเข้า ลบ และแก้ไขข้อมูลต้องใช้ PIN ซึ่งตรวจที่ฝั่ง Google
- ใครมีลิงก์เว็บก็กดเช็คชื่อให้คนอื่นได้ เช่นเดียวกับใบเซ็นชื่อกระดาษ ลายเซ็นจึงเป็นหลักฐานยืนยันอีกชั้น
- URL ของ Apps Script ใน `config.js` จะเห็นได้ใน repository สาธารณะ ซึ่งไม่เป็นไร เพราะคำสั่งสำคัญทั้งหมดต้องใช้ PIN
- อย่าใส่ PIN จริงลงในไฟล์ใดใน repository
- `LOCAL_PIN` ใช้เฉพาะตอนไม่ได้เชื่อม Google Sheets และใครเปิดดูซอร์สโค้ดก็เห็นได้

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| ท้ายหน้าขึ้น "เก็บข้อมูลในเครื่องนี้" | ยังไม่ได้ใส่ `SHEETS_URL` ใน `config.js` |
| "เชื่อมต่อ Google Sheets ไม่ได้" | ตรวจว่า URL ลงท้ายด้วย `/exec` และตั้งผู้ที่มีสิทธิ์เข้าถึงเป็น **ทุกคน** |
| "ยังไม่ได้ตั้ง ADMIN_PIN" | เพิ่มพร็อพเพอร์ตี้ `ADMIN_PIN` ตามขั้นตอนที่ 1 |
| แก้โค้ด Apps Script แล้วไม่มีผล | deploy เวอร์ชันใหม่ตามหัวข้อ "แก้ไขภายหลัง" |
| นำเข้าไฟล์แล้วไม่พบรายชื่อ | ตรวจว่ารายชื่ออยู่ในชีตแรกของไฟล์ และมีคอลัมน์ชื่อ |
